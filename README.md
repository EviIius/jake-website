# Jake Brulato — Spatial Portfolio

Personal portfolio website for **Jake Brulato** (Data Management Analyst at Wells Fargo · Charlotte, NC).

Built around a GameCube-inspired GPU-instanced swarm of 120 beveled crystal cubes paired with Apple Liquid Glass panels, Web Audio glass & marimba sound design, an in-app PDF Résumé Theater, and an **on-demand Color Palette Switcher** (`Indigo Cube`, `Spice Orange`, `Emerald Mint`, `WaveBird Ice`, `Rose Quartz`, and `Jet Black BIOS`).

## Sections

- **Experience**: Wells Fargo (Data Management Analyst; Model Risk Management Extern — Decision Science & AI) and ALG Worldwide Logistics (Freight Forwarder)
- **Projects**: Housing Scraper and FlightTracker
- **Education**: M.S. in Data Science and Business Analytics (4.00 GPA) and B.S.B.A. in Business Analytics (3.74 GPA) at UNC Charlotte
- **Skills**: Languages, Frameworks & Libraries, Infrastructure & Tools, Databases & Data Systems, and Domains
- **About**: Profile bio, metrics, contact details, and downloadable/viewable PDF résumé

## Local Development

```bash
cd frontend
npm install
npm run dev
```

The site runs at `http://localhost:5173`. Press `P` at any time (or click **Palette** in the bottom-left control bar) to switch color palettes on demand.

## Build & Tests

```bash
cd frontend
npm test
npm run build
```
